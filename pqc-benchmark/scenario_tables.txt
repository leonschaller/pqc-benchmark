  UC1 ephemeral wire = pk + ct; latency = keygen + encaps + decaps.
  UC1 static wire = ct; latency = encaps + decaps; pk is pre-provisioned.
  UC2 keeps bytes and milliseconds separate. No composite score is invented.
  UC3 primary footprint = pk + sk; desktop timings are not representative.
